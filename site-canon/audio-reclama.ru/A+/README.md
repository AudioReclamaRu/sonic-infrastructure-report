## Происхождение и статус

- Все три исходных файла находятся в этом каталоге в GitHub по состоянию на 2026-11-26.
- Этот индекс фиксирует наличие файлов и их назначение. Он не приписывает им неподтверждённое происхождение и не подтверждает, что они установлены на production-сайте.
- Содержимое исходных файлов сохранено отдельно; эта правка обновляет только индекс README.
- Live-проверка 26.11.2026: главная показывает 165 demo-ссылок и пять client MP3-ссылок; каталоги demo/client при открытии корня отвечают 403. Пять файлов подтверждены как ссылки в публичном HTML, но их HTTP HEAD не подтверждён. Live llms.txt, robots.txt и sitemap.xml пока отвечают 404. Перед передачей веб-мастеру требуется проверить серверную защиту NDA-файлов и сохранить точечную allowlist только для пяти актуальных публичных ссылок. Текущая цена, лимиты, правки и eligibility покупателей остаются NOT_VERIFIED до сверки интерфейса с действующей офертой.
