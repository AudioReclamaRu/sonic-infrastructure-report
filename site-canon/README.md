# Канонические исходные файлы сайтов

Этот каталог — единый GitHub-реестр отдельных комплектов исходных материалов для официальных сайтов. Он предназначен для хранения, сравнения, ревью, истории изменений и подготовки безопасной передачи файлов уполномоченному веб-мастеру.

## Разделение сайтов

- [Аудио-Реклама•ru — audio-reclama.ru](audio-reclama.ru/README.md): комплект основной студии.
- `audio.plus/`: отдельный комплект Audio+. Каталог зарезервирован; файлы Audio+ будут добавлены отдельно и не смешиваются с материалами основной студии.

## Статус публикации

**Хранение в этом репозитории не является публикацией на сайте.** Официальные сайты остаются read-only для этой работы. Здесь нет автоматической доставки, синхронизации или деплоя в production. Изменения на живом сайте выполняет только уполномоченный веб-мастер в ручном процессе.

Каждый файл имеет собственный статус. В частности, наличие `sitemap.xml` в GitHub не означает, что он одобрен для production: текущий файл явно помечен как REVIEW-ONLY. Аналогично `robots.txt` в комплекте — предложенная политика обхода, а не подтверждение её активации на сервере.
