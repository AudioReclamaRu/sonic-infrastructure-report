# RUTUBE ↔ Official Website Case Crosswalk — 2026-11-17

This crosswalk links a selected set of public RUTUBE assets to named portfolio cases and service examples on the official public website. It is an evidence map, not a rights register or proof that the underlying audiovisual files are identical.

## Confirmed client/service-level matches

- **Braun**: the homepage describes Braun video-ad localization; the RUTUBE asset is titled “Braun CoolTec — локализация видео” and its description states translation and voice-over of a Braun advertising video.
- **Avansa**: the video-service page says the studio voiced a presentation for an internet service for business financial tools; the RUTUBE item is titled “Avansa — озвучивание видео”.

These are high-confidence matches at the client + service level. They are not verified byte-level or frame/audio-level duplicates.

## Important non-matches and limits

- The website lists ABBYY IVR and Vnukovo announcements; the RUTUBE Russian Wealth greeting is a different named client. Do not conflate them.
- The website's JOKASAFE case names Ilya Gulko, and a separate RUTUBE Ilya Gulko voice-over demo exists. No source currently connects that particular demo to the JOKASAFE project.
- Globus Group, IGLA and SpeedFit are website-only within this selected RUTUBE sample. This is not evidence that no platform asset exists.
- TASTE TOMMOROWRUS and SAXO BANK LARS appear in the RUTUBE sample but were not found as named cases on the two website pages checked.

## Method

- `matched_client_and_service`: both sources name the same client and compatible service. Exact media identity remains unverified.
- `website_only_in_current_sample` / `rutube_only_in_current_sample`: absence from this selected sample only, never a claim of global absence.
- Confidence refers to the client/service association, not ownership, licensing, performance, or media identity.
- Public page evidence was read-only. No official website edits, logins, profile actions, uploads, outreach, spending or paid checks occurred.
