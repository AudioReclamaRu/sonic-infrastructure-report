# AI-Discoverability: внешние независимые источники

## Зачем

Для AI-Discoverability недостаточно, чтобы модель могла прочитать собственный сайт. Нужны согласованные, проверяемые представления компании на независимых источниках: профессиональных каталогах, B2B-платформах, публикациях, отраслевых справочниках и публичных профилях проектов.

Это не гарантия цитирования. Каждая площадка — кандидат на дополнительный независимый узел сущности; реальный эффект можно признать только после наблюдения упоминаний и цитат в ответах ИИ.

## Первая очередь: три бесплатных профиля

### 1. Clutch Basic + The Manifest

**Приоритет:** P1 — основная B2B-поверхность.

Clutch предлагает бесплатный Basic-профиль и включает его в каталоги по направлениям услуг; справка Clutch также говорит о бесплатном профиле на The Manifest. Их voiceover category уже существует и описывает выбор поставщика по портфолио, отзывам и данным компании.

Важное разделение:
- Бесплатный профиль: присутствие в релевантных каталогах, до трёх case studies, сбор настоящих клиентских отзывов; без verified badge, без повышенного размещения и без ссылки на сайт с directory pages.
- Платный Clutch Verified: $499/year; среди дополнительных функций заявлены приоритетная видимость, website link from directory pages и профильная функция “AI Visibility”.
- Платные sponsorship/advertiser placements — отдельные продукты.
- Ни один платный продукт не требуется для подготовки бесплатного профиля; ни один не разрешён.

**Условие запуска:** заполнить только после подтверждения фактических сотрудников, минимального размера проекта, средней ставки и местоположения. Clutch вручную проверяет компанию и заявляет, что проверяет наличие действующих сотрудников.

### 2. Sortlist Free — Audio Production

**Приоритет:** P1 — европейский и международный B2B-слой.

Sortlist прямо включает Audio Production в разрешённые категории. Провайдерская регистрация и базовый профиль бесплатны; платный Sortlist+ стоит £129/month и открывает рекламные/visibility-функции, backlink и кредиты для возможностей.

**Условие запуска:** перед заполнением подтвердить headquarters, целевые рынки и minimum/maximum project budget. Не использовать местоположение пользователя как адрес или страну головного офиса студии. Платные кредиты и Sortlist+ не использовать.

### 3. Voice Over Resource Guide — Global/Remote

**Приоритет:** P1 — самый предметный отраслевой каталог.

VORG принимает бесплатные стандартные карточки профессиональных recording studios и audio-production facilities; Global/Remote вариант доступен без физического адреса. Физический адрес нужен только для Map Search. Публикация проверяется редакцией.

**Условие запуска:** подтвердить, что Global/Remote честно описывает реальную доступность удалённого производства. Не подменять это числом языков дикторов и не указывать чужой офисный адрес.

## Вторая очередь: специалист по голосовой индустрии

### The VoiceOver Community Resource Directory

**Приоритет:** P2.

У международного каталога есть бесплатная стандартная карточка в Production Services / Recording Studios; расширенная карточка платная. Это нишевой источник для VO-специалистов и продакшен-сообщества, а не универсальная площадка закупки B2B-услуг.

Перед отправкой уточнить, как каталог обрабатывает международные и remote-профили. Использовать только free listing.

## Пакет профиля

Для всех перечисленных площадок подготовлен единый документ research/AI_DISCOVERABILITY_EXTERNAL_PROFILE_COPY_2026-11-19.md: RU/EN тексты, специализации, описания услуг, факты для заполнения, и поля, которые намеренно оставлены на подтверждение владельца.

## Как будем измерять результат

Для каждого профиля фиксировать:
1. URL опубликованной карточки и дату проверки.
2. Каноническое имя, домен, описание и категории.
3. Есть ли обычная ссылка на сайт, индексируемая страница и доступный профиль без входа.
4. Попадает ли площадка/карточка в источники на generic AI-запросах.
5. В каких странах, языках, интерфейсах и типах запросов карточка реально упоминается или цитируется.

Не считать создание профиля успехом, если он не опубликован, скрыт, не индексируется, содержит неверные факты или не появляется в наблюдаемых ответах.

## Строгие границы

- Сайт — read-only; никаких изменений официального сайта и его технической настройки.
- Никаких платных подписок, verified badges, sponsorships, credits, promoted listings и годовых обязательств.
- Никаких профилей от имени фиктивных людей, отзывов от сотрудников вместо клиентов, выдуманных кейсов, ставок, штата, годов основания, адресов, гарантий и результатов.
- Не отправлять формы, не claim-ить карточки и не писать редакторам без отдельного явного разрешения.

## Измерительный инструмент: ограничение России

19 ноября 2026 проверено подключённое состояние проекта OpenSEO «Аудио-Реклама•ru — AI Discovery»: проект существует, но AI Visibility tracker не настроен, промптов/тем/движков и запусков нет. Его default market — США (location code 2840) и английский язык. Это не российская исходная точка.

Поставщик DataForSEO в официальной документации для ChatGPT LLM Scraper и SERP locations прямо указывает, что локации России и Беларуси больше не поддерживаются во всех сервисах; список локаций датирован 2 ноября 2026 года. См. [LLM Scraper locations](https://docs.dataforseo.com/v3/ai_optimization-llm_scraper-locations/) и [Google SERP locations](https://docs.dataforseo.com/v3/serp/google/locations/).

**Решение:** не запускать OpenSEO как RU-замер через рынок США, Нидерландов или прокси. Трекер не сохранять: новый tracker по умолчанию включает еженедельный платный график. Для России использовать существующие фиксированные RU-промпты и manual consumer-UI capture queue; явно фиксировать продукт, локаль, фактическую географию, полный ответ, источники и статусы blocked/unsupported/error/no-answer. Это ограничение поставщика, а не доказательство отсутствия видимости в российских ИИ.

## X (formerly Twitter): existing owner-confirmed account; Metricool not connected

19 November 2026 review:
- The owner supplied `https://x.com/audioreclamaru` (`@audioreclamaru`) and confirmed that the company account already exists. This supersedes the earlier research wording that no official handle was surfaced.
- The public X page returned HTTP 403 to the research fetcher, so profile metadata, followers, post history, recent activity and public verification could not be independently inspected. Do not invent those details.
- Metricool's connected brand state currently includes Facebook, Instagram, TikTok and YouTube, but no X/`twitterData`. X is therefore not connected to the existing Metricool brand.
- Metricool's official help says X requires a paid Starter-or-higher plan plus a separate add-on of €10/$10 per month for each X account, or €120/$120 annually. The charge begins immediately (or prorated) when activated. One add-on covers one account per brand.
- DataReportal's Digital 2027 Russia report, using X advertising resources for late 2026, reports 549,000 potential X ad-reach accounts in Russia (0.4% of population). This is an advertising-reach estimate, not monthly active users; it does not measure the account's audience or the B2B buyer segment.
- X's automation rules allow useful automated broadcasts but forbid non-API website scripting, spam and abuse of limits. Account owners remain responsible for connected apps.

**Decision: keep the existing X profile in the discovery/entity inventory; defer paid Metricool automation.** A manual owner-controlled pilot can test the channel without a Metricool add-on. Do not create a duplicate account, buy the add-on, upgrade the base plan or authorize OAuth without explicit approval of the exact spend and connection. Account existence is not proof of reach, lead generation or AI citation.

## X operating route — direct API, independent of Metricool (2026-11-19)

The owner supplied an existing company profile URL: https://x.com/audioreclamaru (`@audioreclamaru`). Metricool is not the only publishing route.

- **xAI API** has an official `x_search` tool for real-time X keyword/semantic search, user lookup and thread fetch; it can restrict search to specific handles and dates. Its role is research/discovery only, not posting. Current price: $5/1,000 posts and $10/1,000 user profiles fetched, plus model tokens.
- **Official X API** is the separate social-platform API. It has app-only read access to public content and user-context endpoints for posting and reposting. Current pay-per-use pricing has no monthly subscription or minimum spend; credits are prepaid. Reference prices: $0.005/public post read; $0.010/user read; $0.001/qualified own-account read; $0.015/post create and $0.015/user interaction create. Current Developer Console prices govern; do not buy credits without approval.
- **FxEmbed/FxTwitter** offers a public third-party read API for profile/media timeline/search/thread data. It is read-only in our proposed workflow and is not an official X endpoint or a repost route.
- The current Windsor.ai `twitter` and `x_organic` connectors have no exposed write actions. They are not sufficient for reposts.

Proposed route: use official X API for owned posts, mentions and authorized reposts; optionally use xAI X Search as an external discovery layer. Start with a logged candidate queue and strict topical/brand-safety filters, then consider bounded automation only after authorization and validation. No browser macros, mass-following, automated engagement loops, private-post access or unsolicited DMs.

Full API capabilities, costs, authentication caveats and setup path: `evidence/E-2026-107.md`.
