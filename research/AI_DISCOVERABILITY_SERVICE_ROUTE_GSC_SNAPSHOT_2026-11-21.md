# Короткий срез Search Console по десяти профессиональным маршрутам

**Окно наблюдения:** 22.10.2026—17.11.2026 (27 календарных дней).
**Источник:** подключённая Search Console для свойства `https://www.audio-reclama.ru/`, read-only.

## Основной результат

По десяти официальным страницам профессиональных услуг источник вернул **1 256 показов и 48 кликов**. Это небольшой 27-дневный срез, а не годовой baseline и не метрика семи legacy GEO-страниц.

## Что это меняет в решениях по legacy-страницам

1. **Не объединять «озвучка ролика» с радио автоматически.** В GSC у страницы видеоозвучивания есть запрос `озвучка ролика стоимость`; у страницы радиорекламы — отдельные радио- и аудиороликовые запросы. Это разные измеряемые маршруты, хотя точную границу каждого запроса нужно читать по контексту.
2. **IVR не сводить к произвольному голосовому тексту.** Наблюдения включают организационное приветствие, меню и текст меню — отдельную задачу с профессиональным маршрутом.
3. **Сценарий не смешивать с озвучкой.** GSC возвращает отдельные запросы на сценарии, включая промо-ролики.
4. **Не делать выводов по нулевым кликам на презентации/видеопродакшн.** Период короткий, показы единичные; их URL и назначение остаются отдельными.
5. **Не переносить эти цифры на семь legacy URL.** Их текущие canonical URL в репозитории принадлежат пространству GitHub Pages, а выбранное Search Console property — официальному домену. Извлечение измеряло официальные service routes, а не legacy страницы.

## Ограничения

- Запрошенный годовой диапазон 01.11.2025—17.11.2026 был отклонён текущим пробным доступом Windsor.ai: история доступна только за последние 30 дней. Платное расширение не выполнялось.
- Использовано окно 22.10—17.11.2026; незавершённые свежие данные не включались.
- Запросы — отдельная выборка 122 строк. Их клики не обязаны суммироваться до агрегата по странице; для итогов использованы page-level rows.
- GA4 extraction по десяти профессиональным landing paths за то же окно вернул пустой результат. Это не превращено в нулевой трафик.
- Не измерялись GitHub Pages legacy URL, внешние ссылки, AI citations, лиды, сделки или конверсии.
- Ни один сайт, профиль, рекламный аккаунт, тег или пользовательский путь не изменялся.

Машиночитаемая запись, включая все десять агрегатных строк и выбранные query rows, находится в `RECENT_SERVICE_ROUTE_SEARCHCONSOLE_OBSERVATION.json`.

## Операционное решение

Этот срез укрепляет рекомендацию сохранять профессиональные маршруты и разводить сценарии/радио/видео/IVR, но не даёт права убирать legacy URL. Для объединения по-прежнему нужна статистика самих legacy страниц либо отдельные подтверждённые данные о ссылках и цитированиях.
