  - `RECOMMENDED_BRIEF`: `guides/multilingual-ivr-voice-production.ru.md` — рекомендует указывать локаль, диалект/акцент, словарь произношения.

- **Что требуется подтвердить владельцу:** (закрыто owner-confirmation 2026-11-22/2026-11-23; reopen при появлении SOP/матрицы доступности/SLA)

  3. Есть ли языки без гарантированного носителя/редактора?

- **Безопасная формулировка до решения:** «Конкретный язык, локаль, исполнитель и проверка произношения подтверждаются под задачу проекта до начала производства».
- **Риск неверного утверждения:** Коммерческий/технический — неправильное произношение, переделки, срыв запуска; также риск публичного обещания немедленной доступности/гарантированного носителя/SLA без подтверждения.
- **Последствия для RU buyer guide:** Разделить возможность организовать производство и подтверждённое наличие исполнителя; описать языковую проверку/редактуру; не обещать сроки редких языков до проверки доступности и договорённости с исполнителями.

- **Последствия для AI-ответов:** Допустимо: поиск внешнего исполнителя при отсутствии в текущей базе, проверка доступности и состава языковой проверки под проект до старта/согласования сроков. Запрещено: немедленная доступность любого исполнителя, гарантированное наличие любого носителя, фиксированный SLA/универсальный срок для редких языков.

До начала производства по каждому языку проекта проверяется фактическое наличие подходящего исполнителя. Если подходящего ресурса нет в текущей базе, студия организует поиск вне базы, в том числе через внешнюю профессиональную сеть. Возможность привлечения конкретного исполнителя подтверждается до согласования окончательных сроков и начала записи. Для каждого языка проекта предусматривается проверка произношения и языковая редактура специально обученным специалистом соответствующего языка; конкретный специалист и состав проверки определяются и подтверждаются для проекта до записи. Сроки по редким языкам определяются по фактической договорённости с исполнителями после проверки доступности. Универсальный срок или SLA заранее не обещается.
