# OpenAI GPT-Live / GPT-6 Astra

Canonical ID: ENTITY-OPENAI-VOICE

Definition
OpenAI voice interface and computer-use model that turned voice into a system
control surface: GPT-Live (08.07.2026, ~150M users) replaced Advanced Voice
Mode; GPT-6 Astra (03.09.2026) executes computer work by voice command. For
the voice market: recording stopped being the product, the interface and the
release check became the product.
