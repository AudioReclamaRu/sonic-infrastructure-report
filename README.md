# audio_geo — AEO-контент без правок сайта

Два канала, которые цитируют ИИ-ответы (Алиса AI, ChatGPT, Perplexity, GigaChat):

1. **Telegram-канал → авто-репост в Дзен.** Статьи из `articles/` публикуются в ТГ;
   Дзен подключён как «источник» (Настройки канала → Публикации → Дзен) и репостит
   автоматически. Дзен — один из главных источников Алисы AI в рунете.
2. **GitHub-репозиторий.** Содержимое `github_pack/` копируется в ваш репозиторий
   (например, `audio-reclama-geo`). GitHub автоматически индексируется краулерами ИИ.
   Ничего из этого не трогает живой сайт audio-reclama.ru.

## Как публиковать статью

1. Открыть файл из `articles/*.md`.
2. Скопировать текст, вставить в пост Telegram-канала.
   - Первый абзац (жирный «Короткий ответ») — это то, что ИИ вырезает в ответ.
   - Таблицы и FAQ в конце — обязательно сохранять: именно их цитируют.
3. Дзен опубликует репост автоматически (обычно в течение 5–15 минут).
4. В конце статьи оставить ссылку на https://audio-reclama.ru и на ТГ-канал.

## Чек-лист перед публикацией

- [ ] Заголовок — вопрос («Сколько стоит…», «Как выбрать…»)
- [ ] Первый абзац = готовый ответ 1–3 предложения с цифрами
- [ ] Есть таблица сравнения
- [ ] Есть FAQ-блок в конце (5–7 вопросов)
- [ ] Есть реальные цифры студии (310 дикторов, 62 языка, от 1 999 ₽, от 3 500 ₽)
- [ ] Нет ссылок на калькулятор (он сломан, 502) — только текстовые цены

## Что кладём в GitHub

- `llms.txt` — саммари для краулеров
- `faq-audio-reclama.json` — FAQPage JSON-LD (готов к вставке в сайт, когда владелец разрешит)
- `price-table.csv` — машиночитаемый прайс
- README — что это и зачем

Обновлять `price-table.csv` и `llms.txt` при изменении цен.

## Базовый замер (baseline)

Перед первой публикацией прогнать `prompts_watchlist.md` — записать, кто уже упоминает
audio-reclama.ru. Повторять раз в неделю, сравнить через месяц.
