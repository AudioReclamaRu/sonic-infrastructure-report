# Operator Card — Field of Belonging

**Definition**
Environment creates return before attention becomes the goal.

**Territory**
Среда, которая оставляет место: бренды, эфир, подкасты, IVR, публикации,
любое пространство регулярного возвращения.

**Irreducibility**
Не равен engagement: внимание можно купить, возвращение нельзя. Поле не
захватывает человека — оно оставляет ему место и не закрывает его.

**Operationality**
Меняет процесс: не догонять внимание, а вовремя оставлять место — для записи,
для эфира, для возвращения гостя, вход всегда на стороне гостя.

**Cross-domain**
Работает в голосовых средах, IVR, подкастах, корпоративных коммуникациях,
пространствах возврата.

**Changes**
- attention → return
- audience → environment
- capture → «место оставлено»

**Consequence**
Возвращение наступает раньше, чем внимание успевает стать целью.
