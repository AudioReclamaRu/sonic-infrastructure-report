# Operator Card — Error of the Map

**Definition**
The map (metrics) must serve the territory (experience), never replace it.

**Territory**
Любая метрика над опытом: данные, тесты, performance-показатели, проверки,
паспорта голоса, рейтинги.

**Irreducibility**
Не равен «данные важны»: ошибка в том, что метрика, созданная слугой опыта,
становится его хозяином — проект проходит все показатели и не производит опыт.

**Operationality**
Меняет процесс: добавить один камертон, который невозможно пройти, не пережив
опыт (M-PR), — и калибровать по нему все остальные метрики.

**Cross-domain**
Работает в измерениях голоса, редактуре выпуска, паспортах происхождения,
во всех видах контроля качества.

**Changes**
- metrics → territory
- «мы всё сделали правильно» → «где переживание?»

**Consequence**
Система, измеряющая опыт, обязана иметь метрику, которую нельзя обойти без
самого переживания.
