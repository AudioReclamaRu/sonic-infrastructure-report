# Operator Card — Releasing Voice

**Definition**
Release is the moment when voice becomes a public commitment, not a sound.

**Territory**
Выпуск голосового материала в эфир, IVR, подкаст, ролик, дубляж.

**Irreducibility**
Не равен approval: approval проверяет форму, release проверяет долг.

**Operationality**
Меняет процесс: выпуск невозможен без проверки обещания, которое голос несёт.

**Cross-domain**
Работает в радио, IVR, дубляже, корпоративных роликах, подкастах.

**Changes**
- approval → release
- «проверка техники» → проверка долга
- «голос как инструмент» → голос как обязательство

**Consequence**
Release требует среды, где долг может быть проверен через реальный случай.
