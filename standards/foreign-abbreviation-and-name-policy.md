# Стандарт редакционной обработки иностранных аббревиатур и названий

**Статус:** обязательный редакционный шлюз Telegram-публикаций, версия 2.

## 1. Базовое правило

Иностранная аббревиатура не является обычным словом и не транслитерируется по звучанию. Запрещено превращать латинские буквы в приблизительное русское слово: например, GOP нельзя писать как «Гоп» или «Гоппартия».

Для каждого иностранного сокращения выбирается один из двух способов:

1. **Расшифровать при первом употреблении.** Дать русское название и, при необходимости, исходное полное название на языке источника; затем в скобках сохранить оригинальную аббревиатуру. Далее использовать оригинальную аббревиатуру.
2. **Оставить в оригинале.** Сохранить точное написание исходной аббревиатуры латиницей, если расшифровка не нужна для понимания. Не переводить её фонетически.

Неизвестную аббревиатуру нельзя угадывать. Если точное значение не подтверждено первоисточником, её следует убрать из заголовка/текста либо явно обозначить как нерасшифрованную цитату источника.

## 2. Названия организаций и прозвища

- Официальное название организации важнее краткого политического или медийного прозвища.
- GOP — историческое англоязычное прозвище Республиканской партии США; это не слово «гоп» и не самостоятельное название другой партии.
- В русскоязычном тексте предпочтительно «Республиканская партия США». GOP можно оставить только в оригинальном латинском написании и только когда оно действительно важно для понимания источника.
- RNC раскрывается как Republican National Committee — Национальный комитет Республиканской партии США.
- FCC раскрывается как Federal Communications Commission — Федеральная комиссия по связи США.
- LUC раскрывается как lowest unit charge — минимальная ставка за рекламное время; в русском тексте можно обойтись без самой аббревиатуры.

Примеры в этом разделе нормативные и не дают права механически распространять одну расшифровку на другое событие.

## 3. Машиночитаемый редакционный контракт

Новая публикация использует `editorial_version: 2` и поле `abbreviations` в `feed/concepts.json`.

Пример:

```json
{
  "editorial_version": 2,
  "abbreviations": {
    "FCC": {
      "mode": "expanded",
      "expansion": "Федеральная комиссия по связи США (Federal Communications Commission)"
    },
    "RNC": {
      "mode": "expanded",
      "expansion": "Национальный комитет Республиканской партии США (Republican National Committee)"
    }
  }
}
```

Правила:
- каждый найденный в видимом тексте иностранный акроним должен иметь отдельную запись;
- для `mode: expanded` полное название обязано находиться перед первым употреблением аббревиатуры;
- для `mode: original` акроним остаётся в точном исходном написании латиницей;
- запрещённые фонетические варианты задаются в `forbidden_transliterations`;
- отсутствие словаря, неизвестный акроним, неправильный порядок или фонетическая транслитерация дают `REJECT`.

Автоматическая проверка не заменяет редактора: она проверяет только зафиксированную политику и видимый текст, а не угадывает смысл незнакомой аббревиатуры.

## 4. Источник и статус утверждения

Расшифровка не делает утверждение истинным. Для фактического материала отдельно проверяются:
- точное название стороны, органа или организации;
- первичный документ и дата;
- правовая норма в действующей редакции;
- различие между фактом подачи, утверждением истца, ответом ответчика и решением суда.

Слова «утверждают», «просят», «оспаривают» нельзя заменять на «суд установил» или «правило отменено», пока такого решения нет.

## 5. Контроль выпуска

Перед отправкой редактор проверяет:
1. заголовок отдельно от тела;
2. первое употребление каждого иностранного акронима;
3. полное название и исходное написание;
4. отсутствие фонетического пересказа;
5. соответствие текста первоисточнику;
6. что юридические требования сторон не представлены как установленный судом факт.

Публикация не отправляется, пока все пункты не пройдены.
