# CULTURE OF VOICE — EDITORIAL OBJECT CASES

Эталонные живые кейсы: событие → настоящий объект → почему такая обложка
правильная → почему три другие неправильные. Заполняется человеком вручную
(правило §8 editorial-object-contract.md). CASE 01 заполнен по slоту
kast-kharakterov-2026-09-27 (единственная published-публикация в режиме A).

## CASE 01 — SPLIT

```
EVENT:
  Слепой тест Edison Multi-Cast: каст ролей обгоняет один универсальный голос
  и ведёт слушателя по драматургии выбора бренда.

OBJECT_TYPE: SPLIT
  Один голосовой субъект расщепляется на несколько персонажей-ролей.

EVENT OBJECT:
  subject:    голос
  action:     порождает несколько ролей
  before:     один универсальный голос в слепом тесте
  after:      несколько отдельных голосов-персонажей, каждый со своим характером
  mechanism:  Edison Multi-Cast: один маршрут голоса расщепляется на варианты
              персонажей внутри одной записи
  consequence: персонаж и ведущий конкурируют как субъекты; у канала появляется
              несколько голосов из одной записи
  evidence:   слепой тест Edison Multi-Cast, каст ролей впереди


RIGHT:
  [концепция: микрофон, чей голос расщепляется на четыре фигуры-роли —
  одна говорит, три слушают]
  Микрофон — источник сигнала; от него расходятся четыре тени-роли; единственный
  красный акцент в точке расщепления. Обложка отвечает «что произошло с
  реальностью»: один источник стал несколькими субъектами. Без текста читается
  переход, а не тема.

WRONG:
  [тематическая картинка] Микрофон + человек + наушники на красном фоне.
  Говорит только «это про голос», не несёт изменения.

  [буквальная иллюстрация] Логотип/скриншот продукта Edison Multi-Cast или
  четыре отдельных исполнителя в студии. Иллюстрирует состав события, а не
  переход «один стало несколькими».

  [абстрактная красота] Размытый красно-чёрный градиент без предмета, где
  «красиво», но не видно, что именно изменилось.

REASON:
  Обложка должна показывать ИЗМЕНЕНИЕ (transition), а не тему и не состав.
  Для SPLIT изменение = один источник → несколько субъектов. Правильное решение
  кодирует это одним объектом (источник + расходящиеся контуры) и одной точкой
  красного в месте разрыва. Всё, что рисует «голос» без разрыва единого
  источника, — иллюстрация темы; что рисует готовый результат без генетической
  связи с источником — буквальная иллюстрация; что не рисует предмета — пустой
  декор.
```
