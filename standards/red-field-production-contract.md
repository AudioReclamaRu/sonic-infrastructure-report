# RED FIELD · Production Contract v1.0

> Мы публикуем не новости. Мы публикуем моменты, когда карта реальности меняется.

Это контракт редакции. Документ, после которого любой агент (OpenCode) однозначно понимает:
что считается публикацией, а что — нет. Любое отклонение от контракта = не публикация.

## Главный принцип

**Ноль публикаций лучше одной неподтверждённой.**

Любой пост должен пережить потерю красивых слов. Если после удаления эпитетов остаётся
наблюдаемый факт — публикация имеет право жить.

---

## Инварианты (ломать нельзя)

### I1. Source First

Каждое утверждение опирается на существующий документ.

- `source_resolves()` = PASS.
- GitHub `blob` обязан существовать локально (`repo/blob/<ref>/<path>` → `REPO/<path>`, `os.path.isfile()`).
- Внешняя ссылка должна быть действительно открываемой.
- Если источник исчез — пост не выходит.

Запрещено: «Система показала…» без документа, который можно открыть.

### I2. Demonstration First

Первое предложение обязано показать факт.

Не вывод. Не мораль. Не интерпретацию.

Формула: **Демонстрация → Объяснение → Следствие**.

### I3. Object Survives

После публикации должен остаться один предмет памяти.

Не настроение. Не идея. **Предмет.**

Примеры: четыре тени; микрофон; отпечаток; кольцо; карта; дверь.

Если после просмотра обложки нельзя назвать объект — обложка провалена.

---

## Формат публикации

Каждый концепт обязан содержать ровно эти поля:

| Поле | Обязательно |
| --- | --- |
| `headline` | ✅ |
| `demo` | ✅ |
| `explain` | ✅ |
| `consequence` | ✅ |
| `visual_object` | ✅ |
| `cover_prompt` | ✅ |
| `source` | ✅ |

Любое отсутствующее поле = отказ. Поле `source` хранится в строке фида (`src`), гейт — `source_resolves()`.

## Текстовый контракт

### Headline

- 35–75 символов.
- Запрещено: вопросительные заголовки; кликбейт; оценочные прилагательные без основания.

### Demo

Первая строка отвечает на вопрос «Что реально произошло?».

Одно предложение. Без вывода.

### Explain

Что изменилось. Не больше двух предложений.

### Consequence

Ответ на вопрос «Почему через неделю это всё ещё будет иметь значение?».

Если ответ пустой — публикация отклоняется.

---

## Обложка

RED FIELD остаётся стилем. Но каждая обложка обязана быть уникальной.

### Обязательные элементы

- один главный объект;
- один красный акцент;
- одна доминирующая форма.

### Запрещено

- повтор одинаковой композиции;
- абстрактный красный градиент без объекта;
- текст на изображении.

Обложка должна быть узнаваема даже в размере аватара Telegram.

---

## Editorial QA

### PASS

- источник существует;
- демонстрация наблюдаема;
- объект уникален;
- следствие меняет понимание.

### FAIL

Публикация убивается автоматически, если:

- источник не открывается;
- факт нельзя показать;
- текст остаётся понятным только благодаря красивым словам;
- обложка не имеет собственного объекта.

## Машино-проверяемые правила (реализованы в `publisher.py`)

В `concept_gate()` к отказу добавляются коды:

| Код | Правило |
| --- | --- |
| `qa:headline_len=n` | `n` вне диапазона 35–75 |
| `qa:demo_sent=n` | demo не одно предложение |
| `qa:explain_sent=n` | explain больше двух предложений |

Список правил живёт рядом с `REQ_CONCEPT_FIELDS` и является частью контракта:
правка без согласования с контрактом невозможна.

## Первая эталонная публикация

- **Headline**: Бренд выбирают быстрее, чем успевают услышать весь голос.
- **Demo**: В слепом тесте Edison Multi-Cast более тысячи слушателей чаще предпочитали
  распределённый каст ролей одному универсальному голосу.
- **Explain**: Разница оказалась не в тембре, а в распределении функций: приветствие,
  объяснение, доверие и действие работают как разные роли.
- **Consequence**: Если голос начинает делиться на роли, бренд перестаёт выбирать
  «идеальный голос» и начинает проектировать собственное поведение.
- **Visual Object**: Микрофон и четыре тени. Каждая тень отличается только позой.
  Одна окружена тонким красным кольцом.
- **Cover Prompt**: Black field. One studio microphone in the center. Four human
  silhouettes cast different shadows around it. One shadow is marked by a thin red
  ring. No text. High contrast. Quiet tension. Editorial photography, not illustration.

## Definition of Done

Пост считается существующим только если одновременно выполнено всё:

- `source_resolves()` = PASS;
- все 6 полей концепта заполнены (`source` — через `src` фида);
- обложка содержит уникальный объект;
- первый абзац начинается с наблюдаемого факта;
- следствие отвечает на вопрос «что теперь изменилось»;
- текст можно проверить по исходному документу.

---

## Самое важное изменение

> **Любая публикация должна потерять 80% художественного текста и всё равно остаться сильной.**

Это очень жёсткий тест. Если убрать все красивые формулировки, а публикация всё ещё
сообщает новое знание — значит, канал фиксирует моменты, когда меняется карта реальности,
а не украшает новости.
