# RED FIELD — визуальный характер канала «Культура Голоса»

**Type:** standard/specification (channel visual)
**Status:** approved by editor (13.09.2026)
**Language of record:** RU
**Applies to:** обложки и изображения всех публикаций каналов; визуальный характер «Культура Голоса»
**Related:** ../standards/x13-channel-style.md (голос канала), ../standards/x12-global-monitoring.md

---

## Суть

RED FIELD — не «красивый стиль» и не пресет для картинок, а **визуальное
правило характера канала**. Один и тот же язык, каждый раз новая история.

Фирменный принцип:

> **Чёрное поле + красный сигнал + один физический объект.**
> Человеческое присутствие — через масштаб и объект, а не через силуэт.

Чёрное пространство — мир, ещё не проявился.
Красное — акцент, событие, точка напряжения (сигнал, а не заливка).
Один объект на кадр — предмет, который запомнится (не силуэт-конфликт).
Свет, приходящий извне, — среда воздействует на объект.

Характер канала (и X13, и RED FIELD описывают один и тот же характер):
наблюдатель, точный, спокойный, физический, чуть опасный. Текст называет
изменение, картинка показывает предмет — **два языка одной мысли**.

---

## Связка с заголовком (X13)

Заголовок — это Удар: точка напряжения, называющая изменение.
Картинка — это Удар, показанный физически. **Они не иллюстрируют друг друга.**

Проверка связки:

- пост X13 → заголовок (одна мысль) → изображение RED FIELD (тот же конфликт);
- если обложку поставить к другому посту канала и связка не развалилась —
  картинка не дотягивает до конкретного Удара;
- если обложка повторяет заголовок дословно — это рекламная карточка, а не канал.

## Палитра

| Имя | Значение |
|---|---|
| Void | `#000000` |
| Deep Red | `#180000` |
| Signal Red | `#650000` |
| Active Red | `#B00000` |
| Hot Red | `#FF1A1A` |

**Белый — запрещён.** Даже если очень хочется для контраста. Контраст
создаётся светимостью красного, глубиной чёрного и силуэтом.

---

## Свет

> **Свет не освещает человека. Свет обнаруживает человека.**

Никакого голливудского rim-light. Силуэт почти полностью чёрный, вокруг —
тонкий красный ореол, пространство постепенно проявляется, один участок
изображения активнее остальных. Это практически подпись канала.

---

## Один кадр = одна идея

Не AI-сток: человек + микрофон + наушники + waveform + AI brain + hologram +
текст. Это шаблон.

Только:

- человек,
- красное поле,
- один физический конфликт.

Примеры построения:

- человек в красном поле;
- голосовой силуэт, разделённый на два слоя;
- чёрное пространство, в которое входит красный сигнал;
- человек перед невидимой границей.

---

## Никаких букв на картинке

Вообще. Заголовок живёт в посте. Изображение обязано работать, даже если
удалить весь текст. Это отличает канал от рекламных карточек.

---

## Серийные конфликты

Фирменный — **физический принцип**, а не конкретная картинка. Силуэт и
красный туман не повторяются — каждый пост новый конфликт:

выбор · дефицит · право · власть · внимание · доверие · атака · интерфейс ·
происхождение · память

Серия остаётся серией через принцип, а не через клонирование кадра.

## Примеры серий (14–17.09)

### 14.09 — ВЫБОР

Силуэт между несколькими красными полями. Не пять дикторов — **один человек +
несколько возможных версий его голоса**.

### 15.09 — ДЕФИЦИТ

Силуэт маленький, пространство огромное. Красное поле есть, но чего-то не
хватает. Визуальный смысл: производство стало дешёвым → дефицит переместился.

### 16.09 — ИНФРАСТРУКТУРА

Красные линии проходят **за человеком**, а не поверх. Человек внутри системы.

### 17.09 — ИНТЕРФЕЙС

Силуэт направляет действие в пространство. Не микрофон, не speaker —
**жест → реакция среды**. Голос как интерфейс.

## Место в выпуске

- Текст — X13 (голос канала).
- Заголовок — X13 (Удар, одна мысль) = `headline` концепта (сдвиг, не объект).
- Изображение — RED FIELD (характер канала) = один `visual_object` из концепта.
- Обложка генерируется после финального текста и заголовка (арт-директор),
  только если в `feed/concepts.json` заполнены все четыре поля:
  `headline` / `win` / `visual_object` / `cover_prompt` (гейт публикации).
- Фирменный генератор — `feed/image_gen.py` (v7, арт-директор): чёрное поле,
  красный как акцент, один предмет на новость, без текста на картинке;
  уникальность против последних 20 обложек (dHash + авто-твист кадра).
  Идемпотентность — version-aware через `feed/images/manifest.json`.

## Архитектурное правило: version-aware idempotency ассетов (decision 13.09.2026, дополнено 25.09.2026)

Определение идемпотентности (как зафиксировано в memory):
- Идемпотентность **НЕ равна** «файл существует → пропустить повторную генерацию».
- Идемпотентность = повторный запуск __приводит к тому же итоговому состоянию__, не «ничего не делает, потому что уже был выхлоп».

Три ключа идентификации ассета обложки:
- CONTENT_ID = guid (стабильный контентный слот), например `slepoi-test-2026-09-23`.
- DESIGN_VERSION = версия визуального стандарта фида (RED FIELD = black field, red signal, one object, no text on image), например `red-field-v7`.
- ASSET_HASH = SHA256(CONTENT_ID + ":" + DESIGN_VERSION). **Скоузальный seed больше НЕ входит** — единственный источник истины `feed/images/manifest.json` (single source of truth), путь в POSIX-стиле (`/`, не `\`).

Правило «skip» в генераторе должно быть version-aware:
```
if PNG существует И entry в manifest.json == DESIGN_VERSION И asset_hash совпадает:
    skip (актуальная версия уже сгенерирована)
else:
    regenerate (старый дизайн/версия -> пересобрать, старое в images/backup-red-field/)
```

Проверка наличия файла сама по себе НЕ является критерием актуальности.

## Арт-директор: RED FIELD — система композиции, а не один шаблон (26.09.2026)

RED FIELD **не один шаблон** (единственный способ «объект в чёрном поле + глоток
красного»). Это **система композиции** с инвариантами:

1. Чёрное поле (Void `#000000`) — мир, ещё не проявился.
2. Ровно **один объект** — носитель истории (микрофон, трубка, маска, лист).
3. Красный — **точечный акцент** в одном месте кадра (кольцо микрофона,
   кончик линии), а не заливка и не россыпь.
4. Вариация объекта создаёт ссылку на демонстрацию: тени, слои, искажения,
   следы — сколько «характеров» у объекта, столько вариаций.
5. Ноль текста на картинке.

Композиционная формула для серии «один звук — N характеров»:

- **Один физический объект** в центре (студийный микрофон).
- **N теней объекта** на стене — каждая тень свой характер
  (строгий, улыбающийся, холодный, уверенный). Тени рассказывают историю.
- **Одна точка красного** — у объекта (красное кольцо микрофона).
- Тень — не копия, а **характер в чистом виде**.

Проверка обложки не по шаблону, а по формуле:

> Может ли эта конкретная картинка рассказать демонстрацию поста без текста?
> Есть ли у обложки один узнаваемый предмет и одна точка напряжения?

### Финальный фильтр публикации (24.09.2026, усиливает гейт)

Перед каждой публикацией редактор обязан ответить:

> **«Что читатель увидит нового, чего он не видел минуту назад?»**

Если ответ «ничего» — пост не выходит: даже при существующем E-документе,
зелёном QA и сгенерированной обложке. Однако **единица контента — не E-документ,
а демонстрация**: новость публикуется, если она несёт читателю факт-открытие.
Правило «один документ = один пост» отменено.

## Место в выпуске (обновлено 26.09.2026)

- Текст — X13 (голос канала).
- Заголовок — X13 (Удар, одна мысль, **неожиданность**, а не тема) = `headline`.
- Порядок поста — демонстрация → неожиданность → объяснение → следствие:
  `demo` (факт с конкретикой) → `explain` → `consequence`.
- Изображение — RED FIELD (система композиции) = один `visual_object` из концепта.
- Обложка генерируется после финального текста (арт-директор), только если в
  `feed/concepts.json` заполнены **все шесть** полей: `headline` / `demo` / `explain`
  / `consequence` / `visual_object` / `cover_prompt`.
- Гейт источника: `src` слота обязан резолвиться в существующий локальный документ
  (`source_resolves()` в `publisher.py`); фантомные ссылки → REJECT.
- Фирменный генератор — `feed/image_gen.py` (v7, арт-директор): чёрное поле,
  красный как точечный акцент, один предмет на новость, без текста на картинке;
  уникальность против последних 20 обложек (dHash + авто-твист кадра).
  Идемпотентность — version-aware через `feed/images/manifest.json`.
