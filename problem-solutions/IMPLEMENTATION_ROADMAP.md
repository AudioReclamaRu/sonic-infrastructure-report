## Спринт 3 — публикация

**Статус:** GEO-страница IVR уже собрана и размещена GitHub Pages; это не обновление главного сайта. В связанной GitHub-учётной записи не обнаружен отдельный репозиторий исходников основного audio-reclama.ru, поэтому публикация основного сайта пока зависит от доступа к его CMS/репозиторию.
Выбрать canonical на основном домене; решить, обновлять ли старую статью; добавить внутренние ссылки; проверить title/description/H1/canonical/sitemap/robots/mobile; применить структурированные данные только при соответствии видимому контенту; обновить машинные индексы штатными генераторами; проверить опубликованный URL после деплоя.

GitHub Pages/GEO не считать заменой основному сайту без решения о canonical и индексации. Generated-файлы не редактировать вручную.
