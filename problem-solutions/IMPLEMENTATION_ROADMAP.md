# План внедрения problem-first стратегии

План задаёт последовательность, не гарантирует сроки или поисковый эффект.

## Спринт 0 — направление и инфраструктура
- [x] Создать манифест, библиотеку, шаблон и backlog.
- [x] Изучить лучшие практики аудио и других отраслей.
- [x] Зафиксировать аудит активов, измерение и правила преемственности.
- [ ] Проверить CI, ссылки и машинные индексы после коммита.

## Спринт 1 — аудит и спрос
1. Экспортировать полный каталог URL сайта и блога.
2. Сопоставить тему, intent, свежесть, услугу, доказательства и аналитику.
3. Сверить guides/, geo/answers/, geo/guides/ и geo/knowledge/query-matrix.json.
4. Измерить спрос по кандидатным кластерам.
5. Выбрать 3–5 проблем, где есть спрос/обращения, компетенция, пробел и доказательство.
6. Утвердить границы услуг и права на кейсы.

## Спринт 2 — пилот
1. «Как спроектировать голосовое меню IVR, чтобы звонящий не терялся» — улучшить существующий guide.
2. «Как подготовить текст телефонного приветствия: цифры, имена, ударения и длительность» — связать с Chronomer и release checklist.
3. «Как выбрать голос для делового ролика» — усилить существующую страницу примерами в контексте.
4. «Как проверить многоязычное объявление» — связать с реальным workflow и разрешённым кейсом.
5. «Почему шумоподавление делает голос искусственным» — только после собственных контролируемых A/B-тестов.

Первые четыре ближе к действующим активам. Пятый — потенциальная техническая тема, не обещание платной реставрации.

## Спринт 3 — публикация
Выбрать canonical на основном домене; решить, обновлять ли старую статью; добавить внутренние ссылки; проверить title/description/H1/canonical/sitemap/robots/mobile; применить структурированные данные только при соответствии видимому контенту; обновить машинные индексы штатными генераторами; проверить опубликованный URL после деплоя.

GitHub Pages/GEO не считать заменой основному сайту без решения о canonical и индексации. Generated-файлы не редактировать вручную.

## Спринт 4 — улучшение
Повторить baseline; изучить запросы и цитирования; собрать незакрытые вопросы; обновить метод и доказательства; развить диагностический граф; масштабировать только то, что показало пользу.

Спринт завершён, когда есть исходные данные, проверяемые решения, publication status, работающие ссылки и измерение. Количество черновиков и коммитов само по себе результатом не является.
