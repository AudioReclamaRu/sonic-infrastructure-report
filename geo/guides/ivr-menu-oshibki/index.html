Голосовое меню IVR: как не потерять клиента

Телефонное меню — первое касание клиента с компанией. Ошибка в пункте меню стоит дороже, чем экономия на озвучке.

Типичные ошибки

  • Слишком много уровней. Больше 3–4 вложений — клиент теряется.
  • Непонятные формулировки. «Отдел по работе с обращениями» вместо «Заказать услугу» запутывает.
  • Разные голоса. Сборка из разных дикторов выглядит непрофессионально.
  • Цифры и адреса без проговаривания. Номера, часы работы, адреса нужно произносить чётко.
  • Нет тестового прогона. Меню утверждают по тексту, а не по звонку.

Правила грамотного IVR

  1. Короткие фразы. Максимум суть: «Нажмите 1, чтобы записаться».
  2. Один голос. Весь сценарий — один диктор, единая интонация.
  3. Логичная структура. Главное действие — в первом уровне.
  4. Проверка на слух. Пройдите меню целиком по тестовому номеру.
