# E-2026-067 — Russia page/query performance on four commercial landing pages

## Method

Google Search Console data were requested through the connected Search Console project with:

- dateRange = last_3_months
- dataState = final
- country = RUS
- dimensions: query × page
- one exact landing-page filter per report.

The connector did not return exact start/end calendar dates for the relative period. Therefore this record preserves the requested relative range and observation date instead of inventing a date window. Counts are sums over the returned query/page rows. Average position is weighted by impressions from those rows. The commercial-intent subset uses a documented regex rule, not manual intent labels.

## Observed page totals

| Landing page | Query rows | Impressions | Clicks | Aggregate CTR | Impression-weighted average position |
|---|---:|---:|---:|---:|---:|
| Advertising audio | 43 | 838 | 3 | 0.36% | 10.69 |
| IVR / phone greetings | 57 | 611 | 4 | 0.65% | 27.59 |
| Video voiceover | 12 | 155 | 2 | 1.29% | 44.74 |
| Translation / localization | 17 | 927 | 10 | 1.08% | 9.62 |

## Commercial-intent rule and sub-results

A query was included in the heuristic subset if it matched one or more of: заказать, цена, стоимость, для компании, для АТС, для банка, для бизнеса, производств, изготовлен. This is a transparent search-term heuristic; it is not a complete or human-reviewed intent taxonomy.

## Interpretation boundary

- The zero-click subset is an observed search outcome for this period and filter, not proof that the page is broken or that no user ever clicked from those queries in other periods.
- Search Console average position is an aggregation, not a fixed rank for every user, device or location.
- These metrics do not disclose a reason for a click or non-click and do not prove a causal effect of page copy, price or competitor activity.
- A competitor comparison can produce hypotheses, but not causality.

**p = 1.0** applies to the returned Search Console rows and calculations over those rows.  
**Falsifier:** an exact rerun with the same project, relative date range and filters that returns materially different rows; retain the original capture and compare dates rather than rewriting history.
