# E-2026-091

## Short statement

15.11.2026 получен поисковый срез домена audio-reclama.ru из базы Serpstat (Google Russia, database code g_ru). Провайдер вернул:

- 5 130 строк доменных запросов, по которым он обнаруживает позиции Audio-Reclama.ru в Google top 100;
- 423 страницы в отчёте top-pages;
- выборки keyword-to-URL для трёх отдельных страниц — хрономера, профиля Сергея Чонишвили и статьи о студиях озвучивания;
- выборки по IVR-странице и странице рекламных аудиороликов;
- объёмные показатели для десяти подготовленных коммерческих фраз (одна фраза не найдена в базе).

Это **оценка стороннего SEO-провайдера**, а не данные GA4, Google Search Console, Яндекс Вебмастера или серверных логов. Поле `traffic` / `traff` — расчётная оценка Serpstat, а не измеренное количество посещений. Провайдер не вернул дату исходного снимка своей поисковой базы; 15.11.2026 — дата получения ответа, а не доказанная дата обновления каждой позиции.

**p = 1,0** относится только к точному содержимому полученных ответов Serpstat на дату запроса и к зафиксированным параметрам запросов. Это не p=1 для фактических кликов, трафика, конверсии или текущей live-позиции в Google.

The 80-row sample from the full-domain query includes:
- strong positions for «аудиореклама» (position 1) and «дикторство» (position 10);
- page mismatch/weak positions for broader phrases such as «озвучка текста» (position 79, landing page /perevodchiki/);

The first 80 rows are only a sample of 5,130 provider rows. No comprehensive query taxonomy or intent audit was completed.

## 9. Priority actions suggested by the data

1. **Protect the chronometer utility.** It is the strongest provider-estimated organic entry page in this sample. Keep the tool functional; audit and improve its explanatory copy around «хронометраж текста» and «хрономер онлайн» (positions 18 and 10), then verify with a later identical provider pull and GSC data.
2. **Align IVR article-to-service routing.** The two informational IVR articles already rank for «запись голосового приветствия» and its related variants, while the service page does not appear in that exact phrase result set. Ensure the articles answer the setup/troubleshooting intent and provide a clear contextual transition to the studio's recording service; the service page should own the order intent.
3. **Make the IVR offer verifiable.** The existing meta description contains 1,000 RUB/one-day claims absent from visible page copy (E-2026-089). This still requires owner confirmation; do not publish or repeat those values as current terms until confirmed.
4. **Preserve the radio-ad page's topical alignment.** It already ranks on related product and sample queries. Build conversion clarity and related internal links rather than duplicate service pages.
5. **Reassess the high-keyword-count “Top 8 studios” article by query intent.** Its many ranking rows include entertainment and named-series queries; high keyword count does not mean high qualified traffic. Do not remove it without GSC/analytics and content-policy review.
6. **Measure the result.** Obtain GSC/GA4/Yandex Webmaster access and establish real clicks, impressions, landing-page sessions, engagement and enquiries. Until then, no real-traffic gain or conversion claim can be made.

## 10. Limitations and negative results

- Serpstat does not disclose the underlying observation timestamp in these returned records.
- Provider traffic is estimated, not actual.
- Provider positions are database-reported, not independently verified live SERPs.
- A DataForSEO live Google SERP request for «хрономер» and «хрономер ру» failed with HTTP 502; no live Google result page was obtained.
- DataForSEO's domain ranked-keywords request also failed with HTTP 502.
- Serpstat's competitors endpoint returned HTTP 429 rate limit and produced no competitor dataset.
- The result for «заказать озвучку диктором» was returned in not_found; this is not evidence of zero search demand.
- No Google Search Console, GA4, Yandex Webmaster, CRM or server log data was connected.

## Falsifier and re-check

- Run the same Serpstat requests with the same database and filters at a later dated checkpoint; compare the returned query set, positions and estimated traffic fields, while noting provider snapshot dates if exposed.
- Use GSC to confirm actual impressions/clicks and the exact landing URL for queries.
- Use GA4/CRM to confirm sessions and qualified enquiries.
- Re-classify a query as a conversion opportunity only after its live SERP and intent are checked; a keyword volume field alone does not establish user intent.
- Any owner-confirmed change to IVR pricing/turnaround or service scope supersedes the unresolved meta/body observation for future documents, while preserving historical evidence.
