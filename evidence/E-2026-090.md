# E-2026-090

## Short statement

15.11.2026 выполнена ограниченная live-проверка раздела блога, семи страниц услуг, трёх категорий каталога дикторов, трёх профилей и четырёх конкурентных страниц.

Подтверждено:

1. Обход по адресу https://www.audio-reclama.ru/blog вернул **138 документов**: 121 URL статей вида .html, 12 URL категорий, корневую страницу блога, три вложенных материала раздела business-sound и один некорректный URL, найденный как переход из статьи.
2. Некорректная ссылка в статье «Как создать свою радиостанцию в интернете (часть 2)» ведёт на внутренний адрес https://www.audio-reclama.ru/blog/https://spacial.com/what-we-do-features/, который возвращает HTTP 404. Ссылка помечена в HTML как «Sam Broadcaster». Предполагаемый исходный внешний адрес https://spacial.com/what-we-do-features/ проверен отдельно и возвращает HTTP 200.
3. Десять из двенадцати проверенных страниц-категорий блога используют один и тот же общий title: «Блог о рекламе, видео, ТВ, радио, звуке, голосе, дикторах и обо всём, что нам интересно». Их meta descriptions различаются по темам; H1 в HTML отражает категорию. Это подтверждённая повторяемость title, но её влияние на клики/позиции не измерено.
4. Семь проверенных страниц услуг в разделах /audio/ и /video/ получены с HTTP 200. В них есть портфолио/демопримеры и формы заказа; их текущий органический трафик неизвестен.
5. Три проверенные страницы-фильтра каталога дикторов возвращают HTTP 200 и имеют отдельные title, descriptions и заголовки H2 под конкретную категорию. В видимом сыром HTML этих трёх страниц не найден H1. Это выборка, а не утверждение о всех 308 фильтрах.
6. В мужской русскоязычной категории отображается счётчик 309 голосов, а в языковом списке этой же страницы — 84 английских и 16 немецких дикторов. Это данные отображаемого фильтра на дату проверки, не инвентаризация всех физических дикторов или узлов записи.
7. В трёх проверенных профилях дикторов основной документ указывает собственный URL в og:url. YouTube canonical tags, видимые в возвращённом объединённом raw HTML, принадлежат документам встроенных YouTube-плееров, добавленным после закрытия основного </head>; их нельзя считать canonical-тегами страницы профиля. В одном из трёх профилей отдельный canonical в основном document head не обнаружен. Массовый вывод о canonical на 703 профилях не делается.
8. Три конкурирующие страницы услуг и один каталог голосов показывают несколько конкретных пользовательских паттернов: понятные этапы заказа, отдельные страницы услуг, тарифы/примеры/отзывы и фильтры выбора диктора. Это наблюдения страниц, а не оценка их конверсии.
9. В четырёх разведочных запросах для коммерческих аудиозадач собственная страница Audio-Reclama.ru была включена в один возвращённый список результатов; в трёх других списках она не обнаружена. Это поисковая разведка Firecrawl, **не** подтверждённые позиции Google, не полный SERP и не статистика поискового спроса.

**p = 1,0** относится только к доступному HTML, тексту, ссылкам, HTTP-ответам и результатам ограниченных поисковых запросов на 15.11.2026. Ни трафик, ни конверсия, ни позиции Google/Yandex не измерены.

## 1. Blog crawl

### Coverage

- Crawl start: https://www.audio-reclama.ru/blog
- Scope: blog path only, external-link following disabled, page limit 160, maximum discovery depth 5.
- Returned: 138 documents; 138 completed; no pagination remained.
- Sitemap map previously returned 137 blog-family URLs. The additional 138th result was the malformed URL discovered through the article link.
- Among the 138 returned documents: 121 .html article URLs, 12 category URLs, one blog root, three nested business-sound articles and one malformed linked URL.
- The single non-200 response in this crawl was the malformed URL described below. This is coverage of the bounded crawl, not a full site-wide broken-link audit.

### Broken link

Source article:
https://www.audio-reclama.ru/blog/kak-sozdatj-svoyu-radiostantsiyu-v-internete-2.html

Anchor text: «Sam Broadcaster»

Observed href:
https://www.audio-reclama.ru/blog/https://spacial.com/what-we-do-features/

Observed response: HTTP 404.

Intended external destination, checked separately:
https://spacial.com/what-we-do-features/ — HTTP 200, page title «What we do – Spacial».

Suggested repair for the site administrator: replace the malformed internal href with the verified external target, preserving the anchor's purpose. Do not redirect the erroneous internal path to the homepage.

- https://www.audio-reclama.ru/blog/video/
- https://www.audio-reclama.ru/blog/translate/

- https://www.audio-reclama.ru/blog/voice-commercials/
- https://www.audio-reclama.ru/blog/diy/

Shared title:
«Блог о рекламе, видео, ТВ, радио, звуке, голосе, дикторах и обо всём, что нам интересно».

The returned meta descriptions differ by category, and category H1 headings such as «Блог / Видео» and «Блог / Дикторство» are distinct. The observation supports a targeted title-template improvement, not a claim that rankings are being suppressed.

## 4. Profile canonical parsing control

Three narrator profiles were rechecked after YouTube URL canonical tags appeared in Firecrawl's combined raw HTML:

- Konstantin Gaichuk:
  https://www.audio-reclama.ru/diktoryi/muzhskie-diktor-golosa/russian-diktor-konstantin-gaichuk.html
- Andrey Petelyaev:
  https://www.audio-reclama.ru/diktoryi/muzhskie-diktor-golosa/russian-diktor-andrey-petelyaev.html
- Alexander Khonin:
  https://www.audio-reclama.ru/diktoryi/muzhskie-diktor-golosa/russian-diktor-alexandr-khonin.html

For the first two profiles, YouTube canonical tags appeared only after the main HTML document's closing </head>, inside appended embedded YouTube player document content. The main document's og:url pointed to the profile URL. The third profile contained no YouTube canonical tag in the returned raw HTML.

**Negative finding:** the YouTube canonical tags are not evidence that Audio-Reclama.ru profiles declare YouTube as their canonical destination. Do not report this as a confirmed canonical defect.

A separate sample check found no self-canonical in the main HTML head of the three inspected profiles. Google-selected canonical status remains unknown and requires Search Console.

## What this evidence does not establish

- No Google Search Console, Yandex Webmaster or GA4 measurements were used.
- No actual query volume, impressions, clicks, average position, sessions, enquiries or conversion rate is known.
- A 404 external-link destination in one blog article is not a site-wide broken-link audit.
- Duplicate category titles are not proof of ranking loss.
- A competitor's visible price, timing, catalogue or navigation is not proof of their conversions or market share.
- The sample of three filters and three profiles is not a complete audit of the 308 filter URLs or 703 profile URLs.
- No website changes, public edits or deployments were performed.

## Falsifier and re-check

- A fresh crawl showing the blog href repaired or the target resolving differently supersedes the status for that later date; preserve this snapshot historically.
- The repeated-title finding changes if a fresh page-head extraction shows that the ten categories no longer share the generic title.
- The filter H1 observation changes when broader template inspection shows a real H1 in the main document for the same filter template.
- Any ranking or traffic claim requires Search Console, Yandex Webmaster or GA4 evidence; the Firecrawl discovery lists cannot falsify or establish such measurements.
