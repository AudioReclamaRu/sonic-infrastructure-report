# E-2026-074 — Official-site AI access, sitemap scale and semantic consistency

## Observation method

- **Observed:** 2026-11-18
- **Public surfaces:** `robots.txt`, `sitemap.xml`, root `llms.txt`, homepage, video-voiceover service page, voice-catalogue categories and the existing video-voiceover article.
- **Fetch method:** read-only public-page fetch; TinyFish text/HTML extraction plus the connected first-party Google Search Console property.
- **Search window:** 2026-08-15 through 2026-11-15, Google Search Console Web, country filter `RUS` where specified.
- **Scope:** no CMS access, no authenticated website administration, no edits, no deployment, no changes to crawler rules.

## 1. Crawler access and machine-readable entry points

### robots.txt

The public file `https://www.audio-reclama.ru/robots.txt` is reachable and contains a broad `User-agent: *` group. Its disallow rules target selected technical/private paths and URL patterns; allow rules explicitly reopen selected public assets, including photos and theme assets.

- No separate user-agent groups for AI crawlers were present in the retrieved file.
- The general wildcard group is therefore the current default rule set for crawlers not named separately.
- This is not proof that every bot fetches the site successfully: server-side rate limits, network access, bot policies and individual crawler behavior remain separate.
- Do not add broad allow rules or rewrite robots.txt without a specific access failure and an owner-approved change.

### Sitemap

The public sitemap is reachable and announces **1,186 URLs**. A direct count of its returned URL list produced:

| Sitemap family | URLs |
|---|---:|
| Individual speaker-profile pages | 703 |
| Speaker catalogue filter/category pages | 308 |
| Blog pages | 137 |
| Project pages | 12 |
| Main URL and other service/tool pages | 26 |
| **Total** | **1,186** |

The catalogue therefore represents 1,012 URLs when its root, filter pages and individual speaker profiles are counted together. This is an existing discovery asset, not a justification for generating further near-duplicate pages.

### Root llms.txt

The public URL `https://www.audio-reclama.ru/llms.txt` returned **HTTP 404 / page_not_found** during the read-only fetch. The `llms.txt` in this GitHub repository is a repository knowledge index and does not substitute for a file at the official site root.

A separate, site-ready candidate is prepared in `research/LLMS_TXT_OFFICIAL_SITE_CANDIDATE_2026-11-18.md`. It is not deployed.

**Interpretation:** the missing root file is a low-cost machine-navigation gap to consider closing. `llms.txt` is an informal proposal, not a ratified search standard and not a proven AI-ranking or citation lever. Treat it as a convenience for agents that choose to fetch it, not as a score-boost guarantee.

The crawler and HTML extraction both found the key missing-H1 problem on the catalogue categories. The limited 50-page audit dated 2026-11-17 independently reported seven existing catalogue pages without H1 and duplicate descriptions on the male/female pages.

### Yandex-specific `noyaca`

The retrieved page metadata showed `robots: noyaca`. This is a Yandex-specific snippet-source directive: it prevents use of an old Yandex Directory description when generating a snippet. It is **not** a `noindex` or `nofollow` directive and does not block general AI crawlers. Do not remove it simply to pursue AI discoverability.

Official reference: https://yandex.com/support/webmaster/en/controlling-robot/metatags

### Structured data

The extraction used for this evidence did not provide a reliable complete raw source view of every page's `<head>` and JSON-LD scripts. **Presence or absence of structured data on the live site remains unverified.** Before adding Organization, WebSite, Service or CollectionPage markup, inspect the actual raw page source and avoid duplicating existing structured data.

## 3. First-party search evidence for existing catalogue pages

For Russia-only Search Console data, 32 speaker-catalogue filter URLs had impressions in the selected 90-day window:

- 8,891 impressions and 154 clicks across those 32 URLs.
- 24 of the 32 returned URLs had zero clicks.
- The "known voices" page contributed 5,816 impressions and 34 clicks (CTR 0.58%, average position 8.8).
- The English-language catalogue contributed 813 impressions and 80 clicks (CTR 9.84%, average position 4.7).
- Male Russian voices: 944 impressions / 13 clicks; female Russian voices: 535 impressions / 16 clicks.

For the "known voices" page:
- Query `дикторы`: 2,635 impressions, 4 clicks, average position 8.8.
- Query `актеры озвучки`: 573 impressions, 5 clicks, average position 9.7.
- Query `актеры дубляжа`: 188 impressions, 1 click, average position 10.6.

This indicates a title/snippet/intent-fit review opportunity. It does not establish that the page is technically broken or that low CTR is caused only by its metadata.

For the video path, E-2026-072 records the separate Russia-only comparison:
- Existing how-to article: 121 clicks / 3,289 impressions, CTR 3.68%, average position 7.2.
- Dedicated video-voiceover service: 2 clicks / 155 impressions, CTR 1.29%, average position 44.7.

The existing how-to article already contains an internal link to the video-voiceover service page. Preserve and improve that established path; do not create a duplicate article or assume the link is absent.

## 4. Priority implications

1. Publish a carefully curated root `llms.txt` candidate only after owner approval; treat it as agent navigation, not a ranking promise.
2. Replace the homepage's generic H1 and description with an unambiguous company/service summary.
3. Add one descriptive H1 to the video-voiceover service page and the seven affected catalogue pages.
4. Make male/female descriptions genuinely distinct. Review the high-impression “known voices” page title/snippet against its broad query mix.
5. Align page title, description, Open Graph `site_name` and social preview text to the canonical brand.
6. Use informative alt text only for meaningful performer portraits, using the name and language shown with that specific profile. Keep decorative/player assets empty; do not infer identity or credentials from an image.
7. Update the existing video how-to on its current URL, reusing the already audited draft and correcting its Open Graph description at the same time.
8. Inspect raw source for existing JSON-LD before deciding whether Organization/WebSite/Service markup is missing.

## 5. Evidence limits

- Sitemap counts describe published URLs, not index coverage or traffic.
- GSC rows omit pages with no returned impressions for the period; 32 observed catalogue pages are not all 308 filter URLs.
- The 50-page audit is a sample, not a complete review of 1,186 sitemap URLs.
- Page metadata extraction is not a Google, Yandex or AI-model ranking test.
- No AI-platform benchmark was run and no AI Discoverability Score improvement is claimed.
- The official website remains READ-ONLY; no file, title, H1, description, schema, sitemap, robots rule or page was changed.
