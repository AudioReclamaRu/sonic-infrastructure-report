# Контракт Мегамозга: AI Discoverability

Эта папка задаёт file-based интерфейс между репозиторием и Мегамозгом. Репозиторий хранит цель, ограничения и очередь полезных изменений. Мегамозг самостоятельно исследует, выбирает, выполняет, проверяет и документирует работу. Владелец не обязан вручную собирать источники, запускать benchmark, переносить выгрузки или вести очередь.

## Источники истины

- AGENT_CONTRACT.json — цель, полномочия, запреты, формат обмена, правила измерений и остановки.
- PUBLISHING_AUTHORITY_2026-11-25.md — разрешение владельца на автономную публикацию только в GitHub/GitLab и quality-gated merge; оба официальных сайта остаются read-only.
- WORK_QUEUE.json — кандидаты на работу; перед запуском перепроверить актуальность, дубли и уже решённые проблемы.
- Операционная модель — логика приоритизации и автономного цикла.
- AGENTS.md, FACT-METHOD.md и профильные стандарты — обязательные общие инструкции.

## Рабочий интерфейс

1. Прочитать обязательные инструкции, контракт и операционную модель.
2. Проверить состояние репозитория, веток, PR, CI и связанных доказательств.
3. Проверить очередь на дубли, устаревшие и уже решённые пункты.
4. Выбрать одну ограниченную задачу с лучшим ожидаемым эффектом относительно риска и усилий.
5. Сформировать assessment.json и plan.json; затем выполнить разрешённую работу.
6. Запустить локальные тесты и CI; сформировать test-report.json и decision-log.json.
7. Создать изолированную ветку и PR/MR. По прямому разрешению владельца от 2026-11-25 разрешено сливать в default branch после успешного прохождения всех обязательных проверок и при отсутствии блокирующих замечаний; это не разрешает запись или деплой на официальный сайт.

Структурированные файлы — основной интерфейс. Не заменять исходные файлы и тесты большими inline-скриптами. Runtime-артефакты могут храниться локально, если они не нужны для истории знаний.

## Публикация и выпуск

Действующие полномочия зафиксированы в [PUBLISHING_AUTHORITY_2026-11-25.md](PUBLISHING_AUTHORITY_2026-11-25.md). Разрешены только существующие канонические репозитории GitHub/GitLab. Для текущей базы знаний целевой проект — `AudioReclamaRu/sonic-infrastructure-report`. Сайты https://www.audio-reclama.ru и https://audio.plus/ read-only; GitHub Pages, автозеркала и любые CMS/серверные изменения запрещены.

## Проверки

Из корня репозитория выполнить: python tools/ai_discoverability_contract.py validate и python -m unittest tools.tests.test_ai_discoverability_contract -v.

Валидатор не обращается к сети, не использует учётные данные, платные API или сессии платформ. Он проверяет форму контракта и очереди, а не исполняет benchmark и не доказывает внешнюю AI-видимость.

## Допуск новых задач

Новая задача обязана указывать конкретное препятствие, решение, которое откроет работа, ссылки на доказательства, гипотезу, проверяемые критерии, границу автономии и правило остановки для измерений. Запросы, выгрузки и benchmark-вопросы не добавляются без решения, которое от них зависит. Блокировка доступа или региона фиксируется как блокер; сбор данных не перекладывается на владельца.
