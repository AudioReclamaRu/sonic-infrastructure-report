# VK: вернуть картинки в посты сообщества vk.com/audioreclamaru

## Причина
Сообщество импортирует ленту по URL, в котором было **10 постов, но без картинок** (jsDelivr кэшировал старую версию). Старые 3 поста VK показывает без обложек.

## Что сделано (автоматически)
- В `feed/rss.xml` картинка теперь встроена как первый HTML-элемент `<description>`:
  `<img src="https://cdn.jsdelivr.net/gh/AudioReclamaRu/sonic-infrastructure-report@main/feed/images/{image}.png"/>`
- Это именно формат, который VK RSS-импорт умеет подхватывать.
- Изменения запушены в git (`426d695`).

## Ограничение кэша jsDelivr
CDN jsDelivr отдавал старую (неполную) версию ленты до ~24ч.
**Надёжный свежий URL (без кэша):**
```
https://raw.githubusercontent.com/AudioReclamaRu/sonic-infrastructure-report/main/feed/rss.xml
```

## Действие владельца (один раз, в VK)
1. vk.com → «Аудио-Реклама•ru» → **Управление** → **Интеграции** → **RSS-импорт**
2. Вписать свежий URL (выше) и **сохранить/пересинхронизировать**
3. Импорт начнёт подтягивать новые посты **с картинками** с сегодняшней даты.
4. **Перезалить старые 3 поста** (без картинок): вручную в VK **скопировать текст + обложку** из `/feed/images/*.png` — правка поста → прикрепить фото.
   (Альтернатива через API со token с правом `wall`: `wall.post` + загруженное фото — по запросу.)

## Когда картинки появятся
- Посты с датой ≤ текущей (12–16.09): на момент срабатывания импорта VK — **с картинкой**.
- Ранее опубликованные 3 поста: только после ручной правки (пункт 4).
