# monitoring/venues.md — живой реестр источников мониторинга

**Type:** registry · **Owner:** intel-контур · **Last updated:** 2026-09-13
**Standard:** ../standards/x12-global-monitoring.md
**Правило:** зона события ≠ язык публикации. Каждый сигнал в scans/intel
носит поля `event_geo` + `source_language`.

Реестр живёт и пополняется по мере расширения контура. Запись:
`регион → язык → медиа → отрасль → URL → частота → статус → последнее
сканирование`. Статус: ACTIVE / ADDED / STALE.
