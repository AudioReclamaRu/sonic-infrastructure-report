# Guides — high-intent international buyer routes

**Purpose:** reusable, source-grounded buyer guidance for enterprise audio and voice-production questions.  
**Status:** repository knowledge assets and localization drafts; these files are not published landing pages on the official website.

One route per distinct buyer task. The four core commercial routes are English-first and have first-pass Spanish, Brazilian Portuguese and Arabic versions. Localized versions remain drafts until a competent native-language reviewer checks terminology, regional phrasing, commercial nuance and technical vocabulary. They must not be described as certified translations.

## Editorial and technical gates

Each route should:
- answer the buyer's task directly at the top;
- connect the need to a publicly documented service and primary source;
- explain workflow, inputs, outputs, rights and technical acceptance;
- distinguish the studio's audio-production work from the client's IT, telecom, media-buying or operational responsibilities;
- describe worldwide language-production capability without implying physical offices;
- avoid unsupported prices, deadlines, outcomes and client endorsements;
- end with a verification/acceptance criterion and a practical next step.

Official service pages remain the primary sources for current commercial scope. Git guides are knowledge assets, not substitutes for current terms or a deployed website route. Official website: https://www.audio-reclama.ru
