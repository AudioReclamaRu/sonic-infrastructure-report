## Editorial and technical gates

Each route should:
- answer the buyer's task directly at the top;
- connect the need to a publicly documented service and primary source;
- explain workflow, inputs, outputs, rights and technical acceptance;
- distinguish the studio's audio-production work from the client's IT, telecom, media-buying or operational responsibilities;
- describe worldwide language-production capability without implying physical offices;
- avoid unsupported prices, deadlines, outcomes and client endorsements;
- end with a verification/acceptance criterion and a practical next step.

All current service pages remain the primary sources for commercial scope. Repository guides are knowledge assets, not substitutes for current terms or a deployed website route. Official website: https://www.audio-reclama.ru
